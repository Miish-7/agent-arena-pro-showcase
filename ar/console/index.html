تجربة المؤسستين المسجّلة

المؤسسة

قارن استجابة تقرير محمي في سياق مؤسستين. يحدّد الخادم المؤسسة من الهوية التي جرت مصادقتها.

المؤسسة المالكة

HTTP 200. تمكّنت المؤسسة المخوّلة من تصدير تقرير التدقيق الخاص بها بصيغة JSON.

المؤسسة الأخرى

HTTP 404. تعذّر الوصول إلى السجل المحمي. شمل الفحص مسارات الأحداث والتحقق في كلا الاتجاهين بين المؤسستين.

تجربة المؤسستين المسجّلة

التقارير والتدقيق

قارن الحقول التي فُحصت في تقارير قرارات المؤسسة والأحداث المسجّلة. تبقى الهويات الفردية وقيم بصمات الإجراءات في السجلات الخاصة.

تقرير PDF

شمل الفحص القرار وسببه وإصدار السياسة. تضمنت الإجراءات المعلّقة أو المعتمدة مرجع الموافقة وبصمة الإجراء.

تصدير JSON

تطابق مرجع الموافقة وبصمة SHA-256 المحسوبة بصورة مستقلة مع PDF وسجل القرار. تتاح هوية المراجع في JSON للمخوّلين.

أحداث القرار

قدّمت أحداث المؤسسة أدلة القرار والموافقة. تكرّر فحص سلامة السجل بعد استعادة قاعدة البيانات الاصطناعية.
