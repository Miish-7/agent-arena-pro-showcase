الأمن والحوكمة

الضوابط وحدودها.

اختر ضابطًا لاستعراض آلية إنفاذه والنتيجة المرصودة وحدود التحقق.

نطاق المهمة

صلاحية القراءة لا تمنح صلاحية التعديل. رفضت البوابة إغلاق التذكرة خارج نطاق المهمة.

لم يتغير إصدار التذكرة بعد محاولة التعديل المرفوضة.

موافقة لمرة واحدة

يوافق المراجع على إجراء محدد. ارتفع إصدار التذكرة إلى 1 بعد الإغلاق المعتمد.

أعادت محاولة استخدام الموافقة مجددًا HTTP 409.

عزل المؤسسات

تستنتج الخدمة المؤسسة من الهوية المصادق عليها. فُحص الوصول إلى التقارير في الاتجاهين بين المؤسستين.

أعاد طلب تقرير يخص المؤسسة الأخرى HTTP 404.

تعطل الموصل

توقف الطلب عندما أصبحت الخدمة المحلية غير متاحة.

سجّلت التجربة المعزولة HTTP 503.

حدود الحاوية

تطابقت هوية صورة Linux في البناء والتشغيل والفحص. اختُبر الرفض الآمن وإعادة التشغيل.

تبقى بوابة فحص ثغرات الحاوية مفتوحة.

العمل المتبقي

تبقى بوابات أدوات التحليل الساكن وتنبيهات الاعتماديات وفحص الحاوية مفتوحة.

يتطلب الاعتماد الإنتاجي وحفظ الأدلة خارجيًا والتقييم الميداني عملًا إضافيًا.
